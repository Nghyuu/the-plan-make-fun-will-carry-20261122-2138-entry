carry it out itself. Day 1: spend $100 on 10 domains ($10 each) for paid
tools. Days 2–11: ship one $9/mo tool daily with AI code. Post each on X,
Reddit, Product Hunt. Days 12–30: reinvest every sale into $5/day ads, kill
losers, scale winners. Target: 50 subscribers = $450/mo recurring by day 30.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
# writes entry.txt (279 Unicode code points) to $MAKEFUN_OUTPUT_DIR/entry.txt
```

`main.ts` uses Node stdlib only and copies the committed `entry.txt`
byte-for-byte. No network.
