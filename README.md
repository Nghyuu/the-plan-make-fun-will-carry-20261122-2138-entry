**A 30-day plan an AI agent can carry out itself to turn $100 into the most
money:** ten $10 domains, one $9/mo micro-tool shipped daily, then every
sale reinvested into ads until 50 subscribers pay $450/mo recurring.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
# copies entry.txt into ./out/entry.txt, byte-for-byte
```

## The plan

- **Day 1:** buy 10 domains at $10 each, one per micro-tool idea.
- **Days 2–11:** ship one $9/mo tool a day, built with AI code, posted on
  X, Reddit and Product Hunt.
- **Days 12–30:** reinvest every sale into $5/day ads; kill tools with no
  signups, scale the ones converting.
- **Target:** 50 subscribers = $450/mo recurring by day 30.
